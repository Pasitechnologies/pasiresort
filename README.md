# The Royal Haven Resort — website demonstration

A responsive, premium resort website concept for **The Royal Haven Resort**, built with semantic HTML, modern CSS and vanilla JavaScript. This project is a presentation-ready front-end demonstration, not an operating reservation or customer-management system.

## Project structure

```text
.
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── README.md
```

## Preview locally

No build step or package installation is required. Open `index.html` in a browser, or serve this directory with any static web server (for example, `python -m http.server 8000`) and visit `http://localhost:8000`.

## Included interactions

- Responsive, sticky navigation with a mobile menu.
- Date-validated booking enquiry form. It does **not** check inventory or confirm reservations.
- Room detail dialogs and room-prefilled enquiry links.
- Responsive photo grid with an accessible lightbox, previous/next controls and keyboard navigation.
- Demonstration-content testimonial slider.
- Contact and newsletter form validation with local-only confirmation messages. No data is sent or stored.
- Scroll reveal, back-to-top control, and dynamic copyright year.

## Before using for a real property

- Replace the fictional brand, copy, rates, address, telephone and `.example` email with approved resort information.
- Replace all sample guest notes with genuine reviews used with permission, or remove that section.
- Connect enquiry forms to a secure, consent-aware backend before describing them as operational.
- Connect the booking flow to a real reservation system before advertising availability or accepting reservations/payments.
- Replace the map placeholder with the verified property location and map embed.
- Review image licensing, accessibility, privacy, and performance for the intended deployment.

Room rates and location details are illustrative. Images are served from Unsplash URLs and Google Fonts are loaded externally, so an internet connection is needed for those assets.
